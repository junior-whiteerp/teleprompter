# Teleprompter que grava

Teleprompter para o celular que grava o vídeo enquanto o texto rola perto da câmera. Roda no navegador, de graça, sem app.

- O texto rola numa faixa no topo da tela, perto da câmera frontal, e não aparece na gravação.
- Contagem 3-2-1, velocidade e tamanho da letra ajustáveis, troca de câmera, espelho para teleprompter de vidro, 720p/1080p/4K.
- No fim, "Salvar no celular" abre o compartilhar do sistema (no iPhone, Salvar Vídeo).
- Roteiros e ajustes ficam salvos só no navegador do aparelho (localStorage). Nada é enviado a servidor.

Abra em https://junior-whiteerp.github.io/teleprompter/ e, no iPhone, use Compartilhar → "Adicionar à Tela de Início" para abrir como app.

Lembretes entre colchetes no roteiro, como `[pausa]` ou `[sorriso]`, aparecem pequenos e não são para ler em voz alta.
